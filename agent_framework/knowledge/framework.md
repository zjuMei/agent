# 框架学习笔记

## 工具注册

使用 @tools.tool 装饰同步 Python 函数，就可以将它注册到当前工具表。
函数参数需要类型注解，文档字符串用于描述工具用途。
注册时不会执行函数；收到模型的完整工具调用并校验参数后，框架才执行函数。

## 计算器

calculator 支持四则运算、整除、取余、乘方，以及 sqrt、pi 和 e。
计算器通过受限 AST 解释表达式，不使用 eval 执行任意 Python 代码。

## 会话和记忆

会话记录用于恢复同一个会话的上下文，默认只把最近五个成功轮次提供给模型。
长期记忆通过 /remember 明确保存，可以跨同一用户的不同会话使用。
/clear 只清除当前会话和当前模式的聊天记录；/forget 记忆ID 删除指定长期记忆。

## 文档检索

基础知识库支持 UTF-8 编码的 Markdown 和 TXT 文件。
search_documents 返回相关原文片段、文件路径、行号和引用标识。
基础检索使用英文词和中文相邻双字匹配，不能理解所有同义表达。
